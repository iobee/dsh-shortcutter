# 面板焦点：三个边界标记

打开 `http://127.0.0.1:4381/artifacts/focus-markers-study/`。

本目录是独立的 HTML 交互预览。固定角点已选为 Shortcutter 的生产方案；其它方向保留用于对比。

## 对比

| 方案 | 形状 | 位置 |
| --- | --- | --- |
| 固定角点 | 5 × 5 px 实心圆 | 距面板左、上边界各 6 px |
| 边缘短标 | 2 × 20 px 实线 | 左边界，距上边 8 px |
| 单边强调 | 1 px 实线 | 整条上边，可切为下边 |

三者使用相同的中性灰色和 0.8 不透明度，没有发光或位移动画。
颜色：暗色主题 `#a1a5ad`，亮色主题 `#59616b`。

## 体验

- 顶部按钮或 `1` / `2` / `3` 切换方案。
- 面板菜单切换对话、侧栏、文件、浏览器和终端。也可直接点击面板，或用原有 `s` / `c` / `r` / `e` / `b` / `t`。
- 对话、浏览器、终端可点“进入内容”或按 `i`。进入输入后隐藏标记。
- 对话用 `Esc` 返回；浏览器、终端用 `⌘J` 返回。输入中的数字不会切换方案。
- 切换明暗主题；单边强调可选上边或下边。
- 刷新恢复初始数据。所有内容和终端均为离线示例。

## 实现边界

沿用早期交互原型的面板样本、基础样式和交互脚本。预览工具栏与标记绘制独立于面板内容。

`markers.css` 只作用于独立 `.study-focus` 节点。
该节点直接挂在 body，读取当前面板矩形并采用 fixed 定位；`pointer-events: none`，`aria-hidden: true`。
不依赖面板内的标题栏、标签或内容节点，不增加面板 padding，不变更面板背景或内部控件样式。
ResizeObserver 跟随布局变化，弹层和输入态隐藏标记。

这是对三种视觉方向的比较，不代表已确认实际宿主的所有第三方面板兼容性。
后续集成仍需检查分屏、嵌套面板及边缘紧贴控件时的位置冲突。

浏览器验证和截图保留在本机的 `design-qa.md`、`evidence/`，不纳入源码仓库。
